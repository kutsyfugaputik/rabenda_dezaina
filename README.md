## О проекте

**Rabenda Dezaina** — программный комплекс для автоматизации работы салона красоты «Под феном». Проект объединяет серверное API, Telegram-бота и мобильные приложения, предназначенные для клиентов и мастеров.

Система помогает организовать взаимодействие между клиентом и салоном: от работы с учётными записями и заявками до управления услугами и расписанием. Серверная часть отвечает за обработку запросов и работу с базой данных, а Telegram-бот предоставляет дополнительный канал взаимодействия с пользователями.

Проект состоит из нескольких компонентов, которые могут разрабатываться и запускаться независимо друг от друга.

## Архитектура

Система построена по многокомпонентной архитектуре. Основные части взаимодействуют через серверное API и общую базу данных.

```text
                         RABENDA DEZAINA
                                |
              +-----------------+-----------------+
              |                 |                 |
         Mobile apps       Telegram bot       Backend API
          (Flutter)          (Python)          (Node.js)
              |                 |                 |
              +-----------------+-----------------+
                                |
                         PostgreSQL
                         Database
```

### Компоненты системы

| Компонент | Технологии | Назначение |
|---|---|---|
| `server/` | Node.js, Express | REST API, обработка запросов и бизнес-логика |

Мобильные приложения вынесены в отдельные репозитории. Ссылки на них приведены в разделе [Связанные проекты](#связанные-проекты).

## Установка и запуск

### Требования

Для запуска серверной части потребуются:

- [Node.js](https://nodejs.org/) и npm
- [PostgreSQL](https://www.postgresql.org/)
- Python и pip — для Telegram-бота
- Git — для получения исходного кода

### 1. Клонирование репозитория

```bash
git clone https://github.com/kutsyfugaputik/rabenda_dezaina.git
cd rabenda_dezaina
```

### 2. Настройка базы данных

Создайте базу данных PostgreSQL. Если используете SQL-скрипт из репозитория, выполните его в созданной базе:

```bash
createdb rabenda_db
psql -d rabenda_db -f rabenda.sql
```

Параметры подключения должны соответствовать настройкам проекта.

### 3. Настройка серверной части

```bash
cd server
npm install
```

Создайте файл `.env` в каталоге `server` и укажите параметры подключения к PostgreSQL и необходимые настройки окружения. В частности, сервер использует параметры `PORT`, `DB_USER`, `DB_HOST`, `DB_NAME`, `DB_PASSWORD` и `PG_DUMP_PATH`.

Пример структуры конфигурации:

```env
PORT=3000

DB_USER=your_db_user
DB_HOST=localhost
DB_NAME=rabenda_db
DB_PASSWORD=your_db_password

PG_DUMP_PATH=/path/to/pg_dump
```

Не добавляйте файл `.env` с реальными паролями и секретами в Git.

Запуск сервера:

```bash
node index.js
```

Для режима разработки также предусмотрен скрипт:

```bash
npm run dev
```

После запуска API доступно по адресу:

```text
http://localhost:3000/api/
```

Фактический порт определяется переменной `PORT`.

### 4. Настройка Telegram-бота

Перейдите в каталог `bot` и установите зависимости Python, указанные в файлах проекта. Перед запуском настройте токен Telegram-бота и параметры подключения, если они требуются его конфигурацией.

Точка входа и способ запуска определяются текущей структурой каталога `bot`.

## Работа с базой данных и резервными копиями

Сервер использует PostgreSQL и Sequelize. При запуске выполняется проверка соединения с базой данных и синхронизация моделей.

В серверной части также предусмотрено резервное копирование базы данных с помощью `pg_dump`:

- резервная копия создаётся при запуске сервера;
- автоматическое резервное копирование выполняется каждые 30 минут;
- файлы сохраняются в каталоге `server/backups/`;
- для выполнения резервного копирования необходимо корректно указать `PG_DUMP_PATH` и параметры доступа к БД.

## Структура репозитория

```text
rabenda_dezaina/
├── bot/                    # Telegram-бот на Python / Aiogram
├── server/                 # Серверная часть на Node.js
│   ├── index.js            # Точка входа сервера
│   ├── package.json        # Зависимости и npm-скрипты
│   ├── routes/             # Маршруты API
│   ├── modules/            # Модули, включая подключение к БД
│   ├── error/              # Обработка ошибок
│   └── utils/              # Вспомогательные функции
├── rabenda.sql             # SQL-скрипт базы данных
├── rabenda.backup          # Резервная копия базы данных
└── .gitignore              # Исключения Git
```

*Вложенные каталоги могут дополняться по мере развития проекта.*
